# Shellit Portal Backend & Admin Panel (PocketBase)

Официальный бэкенд и панель администрирования веб-портала **Shellit** на базе **PocketBase** (встроенный SQLite, Realtime API, авторизация, загрузка файлов).

---

## Архитектура и функции

* **Готовая панель администратора:** доступна по адресу `http://127.0.0.1:8090/_/`
* **Коллекции:**
  * `roadmap_items` — дорожная карта с синхронизацией из `docs/roadmap.data.json` и живыми апвоутами пользователей.
  * `plugins` — каталог расширений `.shellit` с модерацией (`published`, `pending_review`).
  * `feedback_reports` — сообщения, заявки на фичи и баг-репорты от пользователей с сайта.
  * `releases` — реестр версий дистрибутивов и чексумм.

---

## Запуск

### Вариант 1: Локально на Windows (PowerShell)
```powershell
./start.ps1
```
Скрипт автоматически скачивает легковесный бинарник `pocketbase.exe` (15 МБ), если его нет, применяет миграции коллекций и запускает сервер на порту `8090`.

### Вариант 2: Docker Compose (для сервера или VPS)
```bash
docker compose up -d
```

---

## Миграция на рабочий VPS / Сервер

Перенос на сервер занимает 30 секунд:
1. Скопируйте папку `servers/portal_backend` на сервер.
2. Запустите `docker compose up -d`.
3. В настройках сайта укажите: `PUBLIC_POCKETBASE_URL=https://pb.shellit.dev`.
Вся база данных SQLite и загруженные файлы хранятся в папке `pb_data/`.
