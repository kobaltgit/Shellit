Добро пожаловать в **Shellit** — кроссплатформенный SSH & SFTP клиент нового поколения, созданный для инженеров, ценящих приватность, контроль и скорость работы.

## 1. Первое включение и создание хранилища

При первом запуске Shellit предложит вам задать **Мастер-пароль** для локального хранилища:

:::tip[Безопасность Zero-Knowledge]
Мастер-пароль используется для вычисления ключа шифрования базы данных через алгоритм **Argon2id**. Пароль никогда не сохраняется в открытом виде и не передается по сети. Если вы забудете мастер-пароль, восстановить доступ к зашифрованным ключам невозможно.
:::

## 2. Добавление первого сервера

1. Нажмите кнопку **«Добавить хост»** или воспользуйтесь сочетанием `Ctrl+N` (`Cmd+N`).
2. Заполните параметры подключения:
   * **Название:** например, `prod-k8s-master`
   * **Хост / IP:** `65.108.57.255`
   * **Порт:** по умолчанию `22`
   * **Пользователь:** `root` или имя вашего системного пользователя
3. Выберите среду (**Environment**):
   * `PROD` — активирует защиту **Prod Guard**;
   * `STAGE` — тестовая среда;
   * `DEV` — локальная разработка.

## 3. Матричные сплиты (2x2) и Broadcast Input

В любой вкладке терминала вы можете разделить экран:
* `Ctrl+Shift+D` — вертикальный сплит;
* `Ctrl+Shift+E` — горизонтальный сплит;
* `Ctrl+Shift+B` — включить **Broadcast Input** (одновременный ввод во все панели).

![Матричные сплиты 2x2 и режим Broadcast Input в Shellit](/screenshots/08_matrix_tiling_2x2.png)

## 4. Палитра команд Omni-Bar (`Ctrl+K`)

Нажмите `Ctrl+K`, чтобы открыть строку быстрого поиска. Вы можете искать серверы по названию, тегам, IP-адресу или выполнять сохраненные сниппеты прямо с клавиатуры без использования мыши.
