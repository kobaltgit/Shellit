# Каталог плагинов и расширений Shellit (Plugins & Extensions)

В этой директории собраны готовые плагины, интеграции и языковые пакеты (`.shellit`) для расширения возможностей Shellit.

---

## 🧩 Готовые плагины (Feature Plugins)

| Плагин | Файл для скачивания | Версия | Описание |
|:---|:---|:---|:---|
| **MCP Server (AI Gateway)** | [**`mcp_server.shellit`**](mcp_server.shellit) | `1.0.0` | Официальный шлюз Model Context Protocol (MCP 2024-11-05, SSE) для подключения ИИ-ассистентов (Cursor, Claude Desktop, Windsurf) к вашим серверам с защитой PROD Guard |
| **Docker Monitor** | [**`docker_monitor.shellit`**](docker_monitor.shellit) | `1.0.0` | Мониторинг запущенных Docker-контейнеров на удаленном хосте в реальном времени (CPU, RAM, логи, перезапуск) |

> **Примечание:** Плагины **MCP Server** и **Docker Monitor** поставляются «из коробки» и уже встроены в дистрибутив Shellit (их можно включать и отключать в настройках). Файлы `.shellit` здесь размещены для автономной переустановки или ручного обновления.

|:---|:---|:---|:---|
| **Русский язык** (Russian) | [**`russian_lang_pack.shellit`**](russian_lang_pack.shellit) | `1.0.0` | Полный перевод интерфейса на русский язык (527+ ключей) |

### 🚀 Как установить плагин или языковой пакет:
1. Скачайте необходимый `.shellit` файл из таблицы выше.
2. Запустите Shellit и откройте раздел **«Плагины»** в боковом меню.
3. Нажмите кнопку **«Установить .shellit»** в правом верхнем углу и выберите скачанный файл.
4. Плагин или язык применится мгновенно!
