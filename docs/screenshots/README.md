# Скриншоты и медиа-ассеты Shellit для сайта и документации

В этой папке хранятся исходные высококачественные скриншоты интерфейса **Shellit**, используемые на промо-странице сайта (`apps/website`), в интерактивном блоке демонстрации возможностей (Sticky Scrollytelling) и в базе знаний (Вики).

---

## 1. Регламент подготовки скриншотов

1. **Формат и качество:**
   * Формат: `PNG` без потерь качества (Astro при сборке сайта автоматически оптимизирует их в `.webp` / `.avif`).
   * Разрешение окна: `1920x1080` (Full HD) или `1440x900` с системным масштабом 100% или 125%.
2. **Приватность и безопасность (Zero Credentials Leakage):**
   * **Никаких реальных секретов:** не снимать настоящие боевые пароли, секретные ключи или приватные токены.
   * Для серверов использовать красивые демонстрационные метки и адреса:
     * `web-prod-01` (`10.0.1.15`), `db-stage-replica` (`10.0.2.40`), `dev-gateway` (`192.168.1.100`).
3. **Единая стилистика:**
   * Тёмная тема: **Obsidian Dark** (фирменная палитра Shellit).
   * Аккуратное окно программы: без посторонних элементов рабочего стола, панелей задач Windows или сторонних окон.

## 3. Размещение готовых файлов
Готовые скриншоты просто сохраняйте в эту папку (`docs/screenshots/`) под соответствующими именами из таблицы. Скрипт сборки сайта в `apps/website` автоматически подхватит их при генерации ассетов.
