# 🛡️ Shellit v0.8.6 — Universal Command Guard, защита истории Bash и рентген xterm

## 📌 О релизе: Броня боевых серверов

В релизе **v0.8.6** проведена масштабная модернизация подсистемы защиты от деструктивных команд (Command Guard / Prod Guard). В ходе реального тестирования на боевых серверах было выявлено 6 взаимосвязанных дефектов и уязвимостей (`BUG-037` — `BUG-042`), которые были полностью устранены:

1. **Мертвый код на не-Production хостах (`BUG-037`)**: включение тумблера защиты на хостах со средой по умолчанию (`defaultEnv`), `staging` или `dev` не давало никакого эффекта.
2. **Фатальный обход через историю Bash (`BUG-038`, P0 Blocker)**: вызов опасной команды стрелкой вверх (`Up Arrow`) оставлял буфер ввода пустым, пропуская команду на сервер без перехвата.
3. **Обход через абсолютные пути и пробелы в регулярках (`BUG-039`)**: команды `/bin/rm`, обратный порядок флагов (`rm -f -r`), системные утилиты `wipefs`, `truncate -s 0`, `systemctl poweroff/reboot`, `chmod -R 777` не распознавались.
4. **Сбои в полноэкранных TUI-редакторах (`BUG-040`)**: нажатие `Enter` в `nano`, `vim`, `less` приводило к ложным срабатываниям и поломке сеанса сигналом `Ctrl+C`.
5. **Рассинхрон в AI Gateway MCP (`BUG-041`)**: шлюз для нейросетевых агентов использовал наивный `contains('rm -rf')`.
6. **Нарушение Zero Hardcoded Strings и отсутствие бейджей (`BUG-042`)**: захардкоженные строки и отсутствие индикаторов сред на вкладках.

В релизе **v0.8.6** создана универсальная система защиты для любых окружений, исключены все найденные обходы и обновлен веб-сайт проекта с новым Актом IX в интерактивной летописи.

## 🔒 Ключевые нововведения и исправления

### 1. Universal Command Guard для всех окружений (BUG-037)
- **Production хосты (`HostEnvironment.production`)**: строгая красная защитная рамка (2.5px, `#FF3333`) и баннер `[⚠️ PRODUCTION ENVIRONMENT: ALL COMMANDS ARE MONITORED]`. Защита активна всегда по умолчанию.
- **Остальные среды (`defaultEnv`, `staging`, `development`)**: при включении тумблера в карточке хоста терминал активирует защитную янтарную рамку (2.0px, `#FFB020`) и баннер `[🛡️ COMMAND GUARD ACTIVE: DESTRUCTIVE COMMANDS BLOCKED]`.
- **Динамический подзаголовок в форме редактирования**: поясняет автоматический режим для серверов Production и избирательный для остальных сред.

### 2. Рентген буфера xterm и очистка системного промпта (BUG-038)
- При нажатии `Enter` терминал выполняет резервный снимок активной строки экрана из буфера xterm: `_terminal.buffer.lines[_terminal.buffer.cursorY]`.
- Метод `DangerousCommandChecker.cleanPromptAndExtractCommand()` отсекает любые шелл-промпты (`user@host:~$ `, `root# `, `(venv) >`) и ANSI-коды, надежно перехватывая вызов опасных команд через историю Bash (`Up Arrow` + `Enter`).

### 3. Перенос в доменное ядро и расширение списка утилит (BUG-039, BUG-041)
- `DangerousCommandChecker` перенесен в ядро `packages/core_foundation`.
- Поддержка абсолютных путей `(?:[^\s]*\/)?` и флагов в любом порядке (`-r -f`, `-f -r`, `--force --recursive`).
- Детектирование: `rm -rf`, `wipefs`, `truncate -s 0`, `systemctl (poweroff|reboot|halt)`, `shutdown`, `init 0`, `dd of=/dev/...`, `mkfs.*`, `chmod -R (777|000)`, `DROP DATABASE/TABLE`.
- Единый валидатор подключен в MCP Server Gateway (`apps/shellit/lib/src/mcp/mcp_provider.dart`).

### 4. Защита TUI-редакторов (BUG-040)
- Добавлена проверка `if (_terminal.isUsingAltBuffer) return;`. Внутри `nano`, `vim`, `less`, `htop` терминал не буферизирует ввод и не шлет прерывания при нажатии Enter.

### 5. Бейджи на вкладках, отступы и полная локализация (BUG-042)
- На вкладках сессий отображаются бейджи сред (`PROD`, `STAGE`, `DEV`), индикатор `[🛡️ GUARD]` и янтарное подчеркивание активной вкладки.
- Плавающий тулбар `[Keys | SFTP | REC | 13pt +]` автоматически опускается под баннер при активной защите.
- Все строки переведены через `context.tr('prod_guard.*')`.
