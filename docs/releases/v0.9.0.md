# 🚀 Shellit v0.9.0 — Семантическая разметка терминала и пошаговая навигация (Semantic Shell Integration & Command Navigation)

## 📌 О релизе / Release Overview

В мажорном релизе **v0.9.0** представлена полноценная семантическая интеграция командной оболочки по стандарту **OSC 133 (FinalTerm / VS Code Shell Integration)**. Бесконечная консольная «простыня» превратилась в интерактивный журнал: каждый промпт оснащен цветным маркером статуса, копированием вывода в один клик и хронометражем выполнения, а навигация по истории команд (`Alt + ↑` / `Alt + ↓`) обеспечивает плавный пошаговый переход без залипаний. На официальном портале опубликован **Акт XII** летописи с признанием и благодарностью авторам оригинального опенсорс-проекта Terminale.

Release **v0.9.0** introduces first-class semantic shell integration via the **OSC 133 (FinalTerm / VS Code Shell Integration)** standard. The infinite console scrollback is transformed into a structured, interactive map: prompts feature colored exit status indicators, 1-click output copying, and execution timing metrics, while step-by-step history navigation (`Alt + ↑` / `Alt + ↓`) enables seamless jumping between command boundaries. On the official portal, **Act XII** of the project chronicle is published, honoring the open-source creators of the Terminale ecosystem.

## 🔒 Ключевые изменения / Key Changes

### 1. Семантическая интеграция командной оболочки OSC 133 (`BUG-046`)
- **Маркеры статуса в левом марджине (`ShellGutterMarkersOverlay`):**
  - 🟢 **Зеленый круг (Success):** Команда завершилась успешно (exit code 0).
  - 🔴 **Красный круг (Failed):** Команда завершилась с ненулевым кодом возврата (exit code $\ne 0$).
  - 🔷 **Бирюзовый пульсирующий круг (Running):** Команда выполняется прямо сейчас в фоновом потоке.
- **Копирование вывода в 1 клик:** Клик мышью по маркеру мгновенно копирует в буфер обмена чистый стандартный вывод команды (`getBlockOutput`) без заголовков промпта и служебных кодов.
- **Хронометраж выполнения:** Перехват клавиши Enter (`notifyCommandStarted`) фиксирует точный момент старта утилиты. При наведении курсора на маркер тултип отображает статус и точную длительность: `Command #3: Success (exit 0) [1.2s]`.
- **Миникарта команд на скроллбаре (`ShellCommandMarkersOverlay`):** Цветные риски на треке прокрутки дают моментальный обзор всей сессии при длинной истории вывода.
- **Тумблер тулбара:** Иконка `[ ⚡ Markers ]` в верхнем меню позволяет в один клик переключать видимость разметки без влияния на ввод.
- **Нулевой след на серверах:** Автоматическая активация в локальных шеллах (PowerShell, Bash) и готовые компактные скрипты инициализации для удаленных серверов (Bash, Zsh, Fish).

### 2. Пошаговая навигация по истории команд (`BUG-048`)
- **Физический последовательный скролл:** Устранен зажим оффсета в `maxScrollExtent` на нижней границе экрана. Алгоритмы `_jumpToPreviousCommand` и `_jumpToNextCommand` ищут блоки, гарантирующие реальный сдвиг оффсета (`targetPixels < currentOffset - 1.0` / `> currentOffset + 1.0`), исключая эффект «залипания».
- **Шорткаты:** Поддерживаются `Alt + ↑` / `Alt + ↓` (Windows/Linux), `⌘ + ↑` / `⌘ + ↓` (macOS), `Ctrl + Shift + ↑` / `Ctrl + Shift + ↓`, а также `Alt + PageUp` / `Alt + PageDown` с независимой проверкой физических клавиш (`physicalKey`).

### 3. Исправление дефектов отображения и стабильности (`BUG-047`)
- **Статус команд в PowerShell:** Устранен сброс переменной `$?` промежуточными присваиваниями внутри функции промпта; статус завершения извлекается первым выражением по стандарту VS Code: `$c = if (-not $global:?) { 1 } elseif ($LASTEXITCODE) { $LASTEXITCODE } else { 0 };`.
- **Чистый интерфейс:** Устранена серая вертикальная полоса справа и фантомные маркеры скроллбара на экранах с коротким выводом (`checkScrollback: true`).
- **Точные координаты:** Координаты маркеров рассчитываются через `RenderTerminal.getOffset(CellOffset(0, block.promptLine)).dy`.

### 4. Веб-портал и Хроника: Акт XII
- Опубликован **Акт XII: Живая простыня терминала / Act XII: The Living Terminal Canvas** (на русском и английском языках) с детальным разбором протокола OSC 133 и решением проблем навигации.
- Выражена открытая благодарность создателю оригинального проекта Terminale — **Фабрицио Ла Роза ([fbrzlarosa/terminale](https://github.com/fbrzlarosa/terminale))**, и форку [uxiew/terminale](https://github.com/uxiew/terminale) за развитие опенсорс-экосистемы.
- Счётчик разобранных дефектов в `StatsHUD` увеличен до **48+**.
