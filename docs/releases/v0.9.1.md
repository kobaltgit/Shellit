# 🚀 Shellit v0.9.1 — Архитектура невмешательства и устойчивость рабочих сессий (Non-Interference Architecture & Workspace Resilience)

## 📌 О релизе / Release Overview

Релиз **v0.9.1** концентрируется на надежности и уважении к пользовательскому окружению:
1. **Архитектура невмешательства в семантической интеграции (`BUG-050`):** Полностью ликвидирована автоматическая фоновая отправка управляющих скриптов в поток ввода PTY удаленных SSH-сессий, создававшая визуальный шум и паразитное многострочное эхо. Разметка выключена по умолчанию, а управление интеграцией переведено на прозрачный модальный диалог `ShellIntegrationSetupDialog`.
2. **Восстановление и перезапуск локальных терминалов (`BUG-049`):** Устранено зависание восстановленных локальных консолей (PowerShell, CMD, WSL) в спящем режиме после перезапуска программы. Добавлена привязка профилей шелла при десериализации, запуск PTY в существующую вкладку (`launchLocalTerminalForTab`) и адаптирован экран ожидания `TerminalConnectingView`.

Release **v0.9.1** focuses on connection hygiene, non-interference, and workspace session resilience:
1. **Non-Interference Shell Integration Architecture (`BUG-050`):** Eliminated automated background injections into remote SSH PTY input streams that caused command echoing and line wrapping. Markers are disabled by default, and setup is now driven by an explicit modal dialog (`ShellIntegrationSetupDialog`).
2. **Local Terminal Restoration & Relaunch (`BUG-049`):** Fixed workspace tab restore for local shells (PowerShell, CMD, WSL) which previously hung in an idle state without starting. Added shell profile re-association, dedicated PTY injection into existing tabs (`launchLocalTerminalForTab`), and adapted `TerminalConnectingView`.

## 🔒 Ключевые изменения / Key Changes

### 1. Архитектура невмешательства в шелл-интеграции (`BUG-050`)
- **Удаление фонового спама в PTY:** Из `TerminalSessionRegistry` вырезаны фоновые таймеры и автоматическая отправка скриптов в `inputStream`. Клиент гарантирует нулевую отправку служебных команд без прямого волеизъявления пользователя.
- **Выключено по умолчанию:** Отображение маркеров в левом поле и на полосе скроллбара по умолчанию отключено (`_showGutterMarkers = false`), кнопка тулбара `[⚡ Markers]` отображается в спокойном приглушенном сером цвете.
- **Модальный диалог настройки (`ShellIntegrationSetupDialog`):**
  - **Активировать в текущей сессии:** Выполняет компактный хук, завершающийся немедленной очисткой буфера (`; clear\n`). Экран сервера остается кристально чистым, а все последующие команды получают цветные маркеры статуса и хронометраж.
  - **Установить навсегда (`~/.bashrc`):** Дописывает хук в конфигурационный файл пользователя на сервере с последующим применением. При последующих подключениях маркеры подхватываются автоматически.
  - **Скопировать скрипт:** Копирует шелл-скрипт в буфер обмена для ручной инспекции или вставки.
- **Адаптивная верстка:** Диалог обернут в `SingleChildScrollView`, исключая ошибки переполнения `RenderFlex overflow` на экранах любого разрешения.

### 2. Оживление и перезапуск локальных терминалов (`BUG-049`)
- **Резолв профилей шеллов:** При вызове `restoreWorkspaceTabs` передаются доступные системные профили `localShellProfiles` и `defaultShellProfile`. Вкладка безошибочно находит свой шелл по `saved.localShellId` с автоматическим фолбэком на стандартный шелл ОС при отсутствии профиля.
- **Запуск PTY в существующую вкладку:** В `SessionManagerNotifier` реализован метод `launchLocalTerminalForTab`, который запускает процесс псевдотерминала прямо в восстановленную вкладку без создания дубликатов.
- **Разблокировка обработчиков повторного запуска:** Снята привязка к `tab.host != null` в `_handleRetryConnection`, контекстном меню `TopBarTabs.onReconnectTab` и фоновом автоконнекте.
- **Адаптированный экран ожидания (`TerminalConnectingView`):** Для локальных консолей отображается неоновый значок `>_`, название и путь к шеллу, кнопка **«Запустить терминал»** (`Icons.play_arrow_rounded`) и скрыты сетевые этапы SSH.
