# Инструкция для Агента 3: UI, Terminal Renderer & Cross-Platform Team

## 1. Роль и зона ответственности
* **Пакет:** `packages/terminal_ui/`
* **Миссия:** Создание первоклассного, отзывчивого пользовательского интерфейса, эмулятора терминала с высокой частотой кадров, адаптивной навигации для Desktop (Windows, macOS, Linux) и Mobile (Android, iOS).

---

## 2. Дизайн-система и эргономика (на базе референса)
Ориентир интерфейса зафиксирован в [`raw-sources/reference.png`](file:///d:/Projects/active/TermIt/raw-sources/reference.png), но Shellit **не должен быть бездумной копией**.

### Ключевые компоненты:
1. **Главный навигационный шелл (App Shell):**
   * **Левый сайдбар:** Разделы: `Hosts` (Хосты), `Keychain` (Ключи), `Port Forwarding` (Туннели), `Snippets` (Сниппеты), `Known Hosts`, `Logs`, `Plugins` (на Desktop). Сворачивается в компактный режим (только иконки) при уменьшении ширины экрана.
   * **Верхний бар (Top Navigation & Tabs):**
     * Выбор хранилища (Vault selector) с индикатором статуса блокировки (замочек) и синхронизации.
     * Система вкладок (Tabs) активных терминальных сессий и SFTP.
     * Быстрый коннект (`ssh user@hostname`) со встроенной кнопкой "Connect".
     * Кнопки управления окном (для десктопа) и глобальный статус сети.
2. **Каталог серверов (Hosts View):**
   * **Карточка сервера:**
     * Логотип ОС (Ubuntu, Debian, CentOS, Alpine, Arch, Server, Router, Mac, Windows).
     * Пользовательский алиас сервера и реальный IP/хост.
     * Учетная запись (`ssh, user`).
     * **Отличие от референса:** Индикатор живости (Latency dot: зелёный < 50ms, желтый < 200ms, серый offline), бейдж окружения (`PROD`, `DEV`, `STAGE`), теги категорий.
   * **Мультирежимный переключатель:**
     * `Grid View` (плитка по умолчанию).
     * `Dense List View` (компактная таблица для администраторов с 50+ серверами).
     * `Folder Tree View` (иерархическое дерево каталогов).
3. **Omni-Bar / Command Palette (`Ctrl+K` / `Cmd+K`):**
   * Всплывающий модальный поиск в стиле Raycast/Spotlight:
     * Быстрый поиск и подключение к хосту.
     * Запуск сохраненных сниппетов.
     * Управление сплитами (split vertical, split horizontal).
     * Смена цветовой темы оформления.
4. **Эмулятор терминала (Terminal View):**
   * Библиотека рендеринга: `xterm.dart` (`flutter_xterm`).
   * Поддержка TrueColor (24-bit), рендеринг шрифтов с лигатурами (JetBrains Mono, Fira Code, Cascadia Code).
   * Копирование/вставка с поддержкой буфера обмена ОС.
   * **Цветовая палитра по умолчанию:** Deep Slate / Obsidian Dark (#151824, в стиле референса) с переключением на Dracula, Monokai, Nord, OLED True Black, Cyberpunk.
   * **Защита продакшена:** Если хост помечен как `PROD`, активируется тонкая красная рамка терминала и опциональный перехват опасных команд (`rm -rf`, `reboot`, `mkfs`) с модальным подтверждением перед отправкой.
5. **Двухпанельный SFTP менеджер (в отдельной вкладке, как в Termius):**
   * Открывается в отдельной вкладке верхнего меню.
   * Две колонки: слева локальная файловая система, справа удаленная сессия SSH/SFTP.
   * Поддержка Drag & Drop файлов между панелями, очередей загрузки/выгрузки и отображения прогресса передачи.
6. **Система сплитов (Tiling Manager):**
   * Разделение активной вкладки на 2 или 4 независимых терминала (горизонтальный и вертикальный сплит, сетка 2x2).
   * Переключение фокуса по клику или шорткатам (`Alt + Arrow`).
   * Опция **Broadcast Mode** (ввод одного терминала дублируется во все сплиты вкладки).
7. **Адаптивность под Mobile (Android & iOS):**
   * Замена сайдбара на Bottom Navigation Bar или Drawer.
   * **Панель специальных клавиш (Mobile Accessory Bar):** Закрепленная над экранной клавиатурой настраиваемая полоска с кнопками: `Esc`, `Tab`, `Ctrl`, `Alt`, `|`, `/`, `-`, `~`, стрелки курсора `↑ ↓ ← →` с виброоткликом (Haptic Feedback).

## 3. Взаимодействие с другими пакетами
* Зависит только от `core_foundation` (модели хостов, интерфейс `ITerminalSession`).
* Принимает реализации сессий через Dependency Injection / провайдеры (Riverpod).
* Не вызывает сетевой код напрямую — подписывается на потоки `session.outputStream` и отправляет события ввода в `session.inputStream`.

## 4. Локализация и нулевой хардкод UI-строк (Строгое правило)
* **Никакого хардкода текста в виджетах:** Все видимые пользователю надписи (кнопки, заголовки, тултипы, плейсхолдеры, ошибки) извлекаются через расширение `context.tr('ключ')`.
* **Формат ключей:** `<экран>.<компонент>.<роль>`, например `hosts.card.action_connect`, `terminal.toolbar.clear`.
* **Поддержка параметров:** Динамические данные передаются только через `params: {'name': value}` (запрещена ручная конкатенация строк).
* **Экспорт шаблона:** Все новые ключи регистрируются в эталонном словаре для корректного экспорта в `template.json` сторонним переводчикам.
* Подробные правила описаны в [`docs/LOCALIZATION_AND_I18N_GUIDE.md`](file:///d:/Projects/active/Shellit/docs/LOCALIZATION_AND_I18N_GUIDE.md).
